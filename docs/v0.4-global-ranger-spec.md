# v0.4 全局巡林官与身份侧面系统策划案

> 状态：已确认并进入开发
>
> 日期：2026-08-15
>
> 适用版本：v0.4.0

## 一、目的

“密涅瓦的巡林官”代表玩家本人。设计师、人类学研究者等长期身份是同一位巡林官的不同侧面，不是彼此隔离的角色或世界。

本系统需要让玩家切换身份时仍能持续建设同一张地图和同一片森林，同时保留每次行动原本的身份、Skill、Action 与笔记归属。

成功标准：

1. 任一身份完成种植后，巡林官的共享成长立即增加。
2. 切换到其他身份后，巡林等级、地图、累计森林与可移栽树木保持一致。
3. 身份内的 Skill、Action、行动森林与笔记不会混入其他身份。
4. 地图只承担探索和叙事激励，不要求玩家维护 Skill 关联。
5. 旧存档升级后不丢失身份记录，也不会因多个身份曾解锁同一地点而重复扣除资源。

## 二、系统边界

### 2.1 数据归属

| 层级 | 数据 | 规则 |
|---|---|---|
| 巡林官全局 | 巡林经验与等级、金币、已收录树种、增益与背景收藏 | 所有身份共享 |
| 巡林官全局 | 地图发现状态、地点解锁、图志画廊、地图视口 | 所有身份共享 |
| 巡林官全局 | 各树种累计种植数量、可移栽树木余额 | 所有身份共同增加和使用 |
| 身份侧面 | Skill、Action、行动经验、行动时长、行动森林 | 只属于当前身份 |
| 身份侧面 | 植树记录、随笔、系统记录及其 Skill/Action 归属 | 只属于当前身份 |
| 身份侧面 | 当前界面、当前行动、种植任务与昼夜状态 | 随该身份保存和恢复 |

### 2.2 非目标

- 本轮不增加账号、云同步或多人共用一个本地档案。
- 本轮不改变 Skill、Action 与笔记之间的既有归属规则。
- 本轮不增加地点分支选择、随机事件或地图战斗。
- 本轮不重新设计种植计时模式。

## 三、玩家流程与前端规则

### 3.1 身份入口

1. 身份选择页说明“一位巡林官、多个身份侧面”。
2. 身份卡展示该身份自己的技能、行动、笔记和贡献树木。
3. 页面同时展示巡林官共享等级和全局累计树木。
4. 进入任一身份后，都读取同一份巡林官全局进度。

### 3.2 种植与共享森林

1. 玩家仍然在当前身份的某个 Action 中种植。
2. 每个完成周期同时产生两类结果：
   - 写入当前 Action 的树木、经验和行动森林，用于保留来源；
   - 写入巡林官全局经验、累计森林和可移栽树木。
3. 地点投入只减少全局可移栽树木，不减少累计森林，也不修改行动森林。
4. 全局累计森林是终身成果。删除一个身份不会让该累计值倒退。

### 3.3 地图叙事

1. 地图地点只有未发现、已发现、可解锁和已解锁四种进度状态。
2. 已解锁地点展示场景故事、抵达时间和图志内容。
3. 地点不归属于身份、Skill 或 Action。
4. 地图不提供 Skill 选择器、关联森林入口或已删除 Skill 提示。
5. 日常行动与地图的联系只通过“种植树木并投入世界”的资源闭环表达。

### 3.4 删除、导入与导出

1. 删除身份只删除该身份的 Skill、Action、笔记和运行状态。
2. 删除身份不删除巡林官等级、收藏、共享地图、累计森林或可移栽余额。
3. 新版备份同时携带一个身份和巡林官全局进度，便于迁移到另一台设备。
4. 同一份巡林官全局备份重复导入时不得重复增加经验、金币或树木。
5. 旧版单身份备份首次导入时，将其巡林官数据合并到当前全局进度；同一旧身份重复导入时不得重复结算。

## 四、后端规则

### 4.1 持久化

1. 巡林官全局进度与身份存档分别保存，并各自保留可恢复备份。
2. 身份切换只重新载入身份数据，不重置巡林官全局数据。
3. 全局进度写入失败时必须暴露错误；地点解锁必须恢复扣除前状态。
4. 全局主数据损坏时优先使用备份；主副本都不可用时，可从现有旧身份记录重建。

### 4.2 旧存档迁移

1. 首次发现旧结构且尚无全局档案时，读取所有现有身份一次性迁移。
2. 金币与巡林经验相加；树种、增益和背景收藏取并集。
3. 累计森林按所有身份的行动森林相加。
4. 旧地图的已解锁地点取并集，并保留最早的有效抵达时间。
5. 同一地点在多个旧身份中都已解锁时，全局只支付一次地点配方；旧身份重复支付的部分退回可移栽余额。
6. 旧地点记录中的 Skill 关联字段在迁移时丢弃。
7. 每个旧身份只迁移一次，重复启动或重复导入不会重复增加全局成果。

## 五、验收条件

- `SPEC-RANGER-AC-01`：两个身份看到相同的巡林等级、金币、树种收藏与地图状态。
- `SPEC-RANGER-AC-02`：身份 A 完成一个周期后，身份 B 能看到增加后的累计森林和可移栽余额。
- `SPEC-RANGER-AC-03`：身份 B 看不到身份 A 的 Skill、Action 和笔记。
- `SPEC-RANGER-AC-04`：地图详情和画廊中不存在 Skill 关联入口或关联文案。
- `SPEC-RANGER-AC-05`：地点解锁只扣除全局可移栽余额，累计森林与行动森林保持不变。
- `SPEC-RANGER-AC-06`：删除贡献过树木的身份后，全局累计森林与地图不倒退。
- `SPEC-RANGER-AC-07`：两个旧身份升级后合并成果，并对重复地点解锁只计算一次成本。
- `SPEC-RANGER-AC-08`：同一旧身份或同一新版全局备份重复导入不会重复结算。
- `SPEC-RANGER-AC-09`：全局进度重启后恢复；全局写入失败时地点解锁回滚。
- `SPEC-RANGER-AC-10`：新版导出文件可以同时恢复身份内容和巡林官全局进度。

## 六、已确认决策

1. 地图是游戏内叙事和长期激励系统，不承担知识分类职责。
2. Skill 关联只存在于 Action、植树记录与随笔体系中。
3. “共享森林”表示共享总成果，同时保留身份、Skill 和 Action 来源。
4. 地图、累计森林和巡林官成长属于玩家本人，而不是当前身份。
