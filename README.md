## 📖 项目简介

**密涅瓦的巡林官**（Minerva Ranger）是一款带有轻度挂机、行动成长和日志沉淀体验的专注工具。

它不是简单记录“你专注了多久”，而是把专注行为映射到一个持续成长的行动系统里：你选择行动、种植树木、积累经验、沉淀日志，并通过技能、行动、手记和系统记录来生长自己的生活森林。

当前仓库正在 `local-desktop` 分支正式开发 **0.4.0**。全局巡林官与身份侧面、Windows Electron + SQLite 权威存档、事务、旧档迁移、备份恢复和安装器自动化已经进入首个发布候选；通过全部 V0.4 验收前不视为稳定发布。

## ✨ 主要功能

### 1. 行动驱动的专注成长

- 每个 `Action` 都有独立等级、经验、树木和累计时长。
- 专注收益会直接结算到行动，而不是停留在简单标签统计。

### 2. Skill / Action 管理

- 支持创建 `Skill` 和 `Action`。
- 支持按技能展开浏览、拖拽排序和重新归类行动。

### 3. 多存档位

- 支持为同一位巡林官建立多个长期身份侧面。
- Skill、Action、笔记与计时按身份独立保存；巡林官成长和世界进度全局共享。
- 支持新建、进入、重命名、删除、导入和导出身份备份。

### 4. 巡林官手记

- 巡林笔记首页包含 `行动足迹`、`巡林随笔` 和 `系统记录` 三个入口。
- 行动足迹按 `Skill -> Action` 汇总植树记录和关联随笔，也能追溯历史及未分类记录。
- 巡林随笔支持 Markdown 编写、实时预览、搜索、筛选、编辑和删除。
- Markdown 预览会过滤脚本、图片、事件属性和危险链接协议。

### 5. 系统日志与行动操作

- 行动合并、行动删除都会自动生成独立的系统记录。
- 合并或删除时可填写说明，作为操作备注保留。
- 行动合并会同步笔记的目标行动与技能归属；行动或技能删除后，相关记录会降级归档并保留名称快照。

### 6. 地图探索与巡林

- 8 个配置化地点按 `未发现 / 已发现 / 可解锁 / 已解锁` 四种状态呈现，并通过前置地点逐步显现路径。
- 每次完成种植周期都会增加全局累计森林和可移栽树木；地点解锁会原子扣除可用余额，但不会减少行动森林和累计成果。
- 地图与场景画廊由所有身份共享；地点只承担探索叙事，不再关联 `Skill`。
- 支持鼠标拖拽、滚轮缩放、视角复位、昼夜模式、图片降级与地图视口持久化。

### 7. 商店与树种解锁

- 支持使用金币解锁不同树种。
- 已提供基础商店和昼夜切换。

### 8. 本地存档

- Windows Electron 桌面版由主进程独占 SQLite，并把全局档案、身份索引和身份快照作为一个事务提交。
- 浏览器开发环境继续使用 localStorage；桌面首次启动会一次性迁移现有数据且保留旧副本。
- 删除身份不会删除该身份已经贡献的巡林官等级、累计森林和地图成果。
- JSON 导入前自动创建 SQLite 备份，应用内也提供手动备份和受保护恢复入口。
- 数据库使用修订号拒绝陈旧写入，并对损坏、只读、过新模式和不可信 IPC 给出结构化错误。
- Markdown 随笔会保存源文和格式信息，并在重新启动后恢复。
- 支持导入和导出，作为用户可控的备份与迁移入口。

### 9. Windows 安装与卸载

- 安装包使用引导式安装，支持选择当前用户/所有用户范围和程序安装目录。
- 默认卸载只删除应用并保留 `%APPDATA%/minerva-ranger` 中的 SQLite、内部备份和设置，重新安装后可以继续使用。
- 卸载页提供两个互斥单选项：“仅删除应用（推荐）”默认保留数据；“删除应用及全部本地数据”会在不可撤销的二次确认后清理应用数据。用户导出到其他目录的 JSON 不会被删除。
- 覆盖安装和后续更新路径不得触发数据删除。

## 🚀 本地开发

### 环境要求

- `Node.js` `^20.19.0 || >=22.12.0`

### 安装依赖

```bash
npm install
```

### 启动 Web 开发环境

```bash
npm run dev
```

Web 开发环境的长期身份保存在当前浏览器 localStorage；Electron 桌面版保存在系统用户数据目录的 SQLite 中。两者都不依赖账号、网络或外部服务。

### 构建前端资源

```bash
npm run build
```

### Electron 开发与验证

```bash
npm run desktop
npm run test:electron-sqlite
npm run test:electron-app
npm run dist
npm run test:packaged-app
npm run test:installer
```

桌面数据库位于 `app.getPath('userData')/data/minerva-ranger.sqlite3`。安装器破坏性烟雾测试使用独立的 `MinervaRangerSmoke` 应用标识、临时安装目录和独立用户数据目录，不会读写真实玩家档案或正式安装记录。

## 🗂️ 当前主要界面

- `身份选择`：查看巡林官全局成长，并进入、新建、导入或导出身份侧面
- `商店`：购买和解锁树种
- `密涅瓦地图`：探索 8 个地点、投入树木解锁场景，并从画廊回看完整图志
- `森林巡视`：以行动列表浏览某个技能下的行动
- `行动仪表盘`：进行专注、种树和收获
- `巡林笔记`：进入行动足迹、巡林随笔和系统记录
- `行动足迹`：按技能、行动或未分类归属追溯植树记录与随笔
- `巡林随笔`：使用 Markdown 编写、预览、搜索和整理长期记录
- `系统记录`：查看行动合并、删除等审计事件
