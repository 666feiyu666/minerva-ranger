## 📖 项目简介

**密涅瓦的巡林官**（Minerva Ranger）是一款带有轻度挂机、行动成长和日志沉淀体验的专注工具。

它不是简单记录“你专注了多久”，而是把专注行为映射到一个持续成长的行动系统里：你选择行动、种植树木、积累经验、沉淀日志，并通过技能、行动、手记和系统记录来生长自己的生活森林。

当前仓库已经完成 **0.2.0**：在本地单机核心流程之上，重构了巡林笔记，补齐行动档案、Markdown 随笔、系统记录及笔记归属迁移。正式的 **1.0.0** 版本会在核心体验与长期使用流程完善后发布。

## ✨ 主要功能

### 1. 行动驱动的专注成长
- 每个 `Action` 都有独立等级、经验、树木和累计时长。
- 专注收益会直接结算到行动，而不是停留在简单标签统计。

### 2. Skill / Action 管理
- 支持创建 `Skill` 和 `Action`。
- 支持按技能展开浏览、拖拽排序和重新归类行动。

### 3. 多存档位
- 支持多个独立存档位。
- 支持新建、进入、重命名、删除、导入和导出单个存档。

### 4. 巡林官手记

- 巡林笔记首页包含 `行动档案`、`巡林随笔` 和 `系统记录` 三个入口。
- 行动档案按 `Skill -> Action` 汇总植树记录和关联随笔，也能追溯历史及未分类记录。
- 巡林随笔支持 Markdown 编写、实时预览、搜索、筛选、编辑和删除。
- Markdown 预览会过滤脚本、图片、事件属性和危险链接协议。

### 5. 系统日志与行动操作

- 行动合并、行动删除都会自动生成独立的系统记录。
- 合并或删除时可填写说明，作为操作备注保留。
- 行动合并会同步笔记的目标行动与技能归属；行动或技能删除后，相关记录会降级归档并保留名称快照。

### 6. 巡林与地图
- 可从地图直接进入对应技能的森林巡视页。
- 巡视页支持按行动列表浏览，并进入单个行动查看森林详情。

### 7. 商店与树种解锁
- 支持使用金币解锁不同树种。
- 已提供基础商店和昼夜切换。

### 8. 本地存档

- 本地多存档是当前版本的唯一正式数据源。
- 每个存档保留上一份 localStorage 备份；主副本损坏时会尝试恢复。
- 存档索引损坏时会根据实际存档槽重建。
- Markdown 随笔会保存源文和格式信息，并在重新启动后恢复。
- 支持导入和导出，作为用户可控的备份与迁移入口。

## 🚀 本地开发

### 环境要求

- `Node.js` `^20.19.0 || >=22.12.0`

### 安装依赖

```bash
npm install
```

### 启动 Web 开发环境

```bash
npm run dev
```

身份档案保存在当前设备的 localStorage 中，不依赖账号、网络或外部服务。建议定期导出 JSON 备份。

### 构建前端资源

```bash
npm run build
```

### Electron 状态

Electron 入口和打包配置暂时保留。`0.2.0` 已验证 Web 生产资源构建，桌面启动、安装包构建和多平台验收将在 `0.3` 完成后继续。

## 🗂️ 当前主要界面

- `存档选择`：进入、新建、导入导出存档
- `商店`：购买和解锁树种
- `密涅瓦地图`：按技能进入森林巡视
- `森林巡视`：以行动列表浏览某个技能下的行动
- `行动仪表盘`：进行专注、种树和收获
- `巡林笔记`：进入行动档案、巡林随笔和系统记录
- `行动档案`：按技能、行动或未分类归属追溯植树记录与随笔
- `巡林随笔`：使用 Markdown 编写、预览、搜索和整理长期记录
- `系统记录`：查看行动合并、删除等审计事件
