## 📖 项目简介

**密涅瓦的巡林官**（Minerva Ranger）是一款带有轻度挂机、行动成长和日志沉淀体验的专注工具。

它不是简单记录“你专注了多久”，而是把专注行为映射到一个持续成长的行动系统里：你选择行动、种植树木、积累经验、沉淀日志，并通过技能、行动、手记和系统记录来生长自己的生活森林。

当前仓库已经完成 **0.4.0**：巡林官成为唯一的全局成长主体，不同长期身份作为同一个人的侧面，共享地图、巡林等级、收藏、可移栽树木与累计森林。正式的 **1.0.0** 版本会在核心体验与长期使用流程完善后发布。

## ✨ 主要功能

### 1. 行动驱动的专注成长

- 每个 `Action` 都有独立等级、经验、树木和累计时长。
- 专注收益会直接结算到行动，而不是停留在简单标签统计。

### 2. Skill / Action 管理

- 支持创建 `Skill` 和 `Action`。
- 支持按技能展开浏览、拖拽排序和重新归类行动。

### 3. 多存档位

- 支持为同一位巡林官建立多个长期身份侧面。
- Skill、Action、笔记与计时按身份独立保存；巡林官成长和世界进度全局共享。
- 支持新建、进入、重命名、删除、导入和导出身份备份。

### 4. 巡林官手记

- 巡林笔记首页包含 `行动足迹`、`巡林随笔` 和 `系统记录` 三个入口。
- 行动足迹按 `Skill -> Action` 汇总植树记录和关联随笔，也能追溯历史及未分类记录。
- 巡林随笔支持 Markdown 编写、实时预览、搜索、筛选、编辑和删除。
- Markdown 预览会过滤脚本、图片、事件属性和危险链接协议。

### 5. 系统日志与行动操作

- 行动合并、行动删除都会自动生成独立的系统记录。
- 合并或删除时可填写说明，作为操作备注保留。
- 行动合并会同步笔记的目标行动与技能归属；行动或技能删除后，相关记录会降级归档并保留名称快照。

### 6. 地图探索与巡林

- 8 个配置化地点按 `未发现 / 已发现 / 可解锁 / 已解锁` 四种状态呈现，并通过前置地点逐步显现路径。
- 每次完成种植周期都会增加全局累计森林和可移栽树木；地点解锁会原子扣除可用余额，但不会减少行动森林和累计成果。
- 地图与场景画廊由所有身份共享；地点只承担探索叙事，不再关联 `Skill`。
- 支持鼠标拖拽、滚轮缩放、视角复位、昼夜模式、图片降级与地图视口持久化。

### 7. 商店与树种解锁

- 支持使用金币解锁不同树种。
- 已提供基础商店和昼夜切换。

### 8. 本地存档

- 本地巡林官全局档案与身份存档是当前版本的唯一正式数据源。
- 删除身份不会删除该身份已经贡献的巡林官等级、累计森林和地图成果。
- 每个存档保留上一份 localStorage 备份；主副本损坏时会尝试恢复。
- 存档索引损坏时会根据实际存档槽重建。
- Markdown 随笔会保存源文和格式信息，并在重新启动后恢复。
- 支持导入和导出，作为用户可控的备份与迁移入口。

## 🚀 本地开发

### 环境要求

- `Node.js` `^20.19.0 || >=22.12.0`

### 安装依赖

```bash
npm install
```

### 启动 Web 开发环境

```bash
npm run dev
```

长期身份及其进度保存在当前设备的 localStorage 中，不依赖账号、网络或外部服务。建议定期导出 JSON 备份。

### 构建前端资源

```bash
npm run build
```

### Electron 状态

Electron 入口和打包配置暂时保留。`0.3.0` 已验证 Web 生产资源构建及目标桌面视口，桌面启动、安装包构建和多平台验收仍需在发布前单独执行。

## 🗂️ 当前主要界面

- `身份选择`：查看巡林官全局成长，并进入、新建、导入或导出身份侧面
- `商店`：购买和解锁树种
- `密涅瓦地图`：探索 8 个地点、投入树木解锁场景，并从画廊回看完整图志
- `森林巡视`：以行动列表浏览某个技能下的行动
- `行动仪表盘`：进行专注、种树和收获
- `巡林笔记`：进入行动足迹、巡林随笔和系统记录
- `行动足迹`：按技能、行动或未分类归属追溯植树记录与随笔
- `巡林随笔`：使用 Markdown 编写、预览、搜索和整理长期记录
- `系统记录`：查看行动合并、删除等审计事件
