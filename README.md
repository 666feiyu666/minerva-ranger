## 📖 项目简介

**密涅瓦的巡林官**（Minerva Ranger）是一款带有轻度挂机、行动成长和日志沉淀体验的专注工具。

它不是简单记录“你专注了多久”，而是把专注行为映射到一个持续成长的行动系统里：你选择行动、种植树木、积累经验、沉淀日志，并通过技能、行动、手记和系统记录来管理自己的知识森林。

当前仓库处于 **MVP / 0.0.0** 阶段，主要用于验证核心玩法、存档结构、专注结算和桌面端工作流。正式的 **1.0.0** 版本会在核心体验稳定、云同步与长期使用流程完善后发布。

## ✨ 主要功能

### 1. 行动驱动的专注成长
- 每个 `Action` 都有独立等级、经验、树木和累计时长。
- 专注收益会直接结算到行动，而不是停留在简单标签统计。

### 2. Skill / Action 管理
- 支持创建 `Skill` 和 `Action`。
- 支持按技能展开浏览、拖拽排序和重新归类行动。

### 3. 多存档位
- 支持多个独立存档位。
- 支持新建、进入、重命名、删除、导入和导出单个存档。

### 4. 巡林官手记
- 内含 `植树日志`、`系统日志` 和 `巡林日志（预留）` 三个分区。
- 植树日志可编辑，系统日志独立展示，并支持按 `Skill -> Action` 筛选。

### 5. 系统日志与行动操作
- 行动合并、行动删除都会自动生成系统日志。
- 合并或删除时可填写说明，作为日志中的操作备注保留。

### 6. 巡林与地图
- 可从地图直接进入对应技能的森林巡视页。
- 巡视页支持按行动列表浏览，并进入单个行动查看森林详情。

### 7. 商店与树种解锁
- 支持使用金币解锁不同树种。
- 已提供基础商店和昼夜切换。

### 8. 本地存档
- 本地多存档是当前版本的唯一正式数据源。
- 每个存档保留上一份 localStorage 备份；主副本损坏时会尝试恢复。
- 存档索引损坏时会根据实际存档槽重建。
- 支持导入和导出，作为用户可控的备份与迁移入口。

## 🚀 本地开发

### 环境要求

- `Node.js` `^20.19.0 || >=22.12.0`

### 安装依赖

```bash
npm install
```

### 启动 Web 开发环境

```bash
npm run dev
```

当前阶段默认设置 `VITE_ENABLE_CLOUD_SYNC=false`。本地保存不依赖账号、网络或同步服务器。

### 构建前端资源

```bash
npm run build
```

### 启动 Electron 桌面端

```bash
npm run desktop
```

### 构建桌面安装包

```bash
npm run dist
```

当前仓库已配置 Electron 构建目标：
- `macOS`：`dmg`

## 🗂️ 当前主要界面

- `存档选择`：进入、新建、导入导出存档
- `商店`：购买和解锁树种
- `密涅瓦地图`：按技能进入森林巡视
- `森林巡视`：以行动列表浏览某个技能下的行动
- `行动仪表盘`：进行专注、种树和收获
- `巡林官手记`：查看与编辑植树日志、查看系统日志
