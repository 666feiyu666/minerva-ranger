## 📖 项目简介

**密涅瓦的巡林官**（Minerva Ranger）是一款带有轻度挂机与项目经营体验的专注工具。

它不是简单记录“你专注了多久”，而是把专注行为映射到一个持续成长的项目系统里：你选择项目、种植树木、积累经验、沉淀日志，并通过主题、项目、手记和系统记录来管理自己的知识森林。

## ✨ 主要功能

### 1. 项目制专注成长
- 每个 `Project` 都有独立等级、经验、树木和累计时长。
- 专注收益会直接结算到项目，而不是停留在简单标签统计。

### 2. Theme / Project 管理
- 支持创建 `Theme` 和 `Project`。
- 支持按主题展开浏览、拖拽排序和重新归类项目。

### 3. 多存档位
- 支持多个独立存档位。
- 支持新建、进入、重命名、删除、导入和导出单个存档。

### 4. 巡林官手记
- 内含 `植树日志`、`系统日志` 和 `巡林日志（预留）` 三个分区。
- 植树日志可编辑，系统日志独立展示，并支持按 `Theme -> Project` 筛选。

### 5. 系统日志与项目操作
- 项目合并、项目删除都会自动生成系统日志。
- 合并或删除时可填写说明，作为日志中的操作备注保留。

### 6. 巡林与地图
- 可从地图直接进入对应主题的森林巡视页。
- 巡视页支持按项目列表浏览，并进入单个项目查看森林详情。

### 7. 商店与树种解锁
- 支持使用金币解锁不同树种。
- 已提供基础商店和昼夜切换。

### 8. 存档与云端入口
- 本地多存档已经可用。
- 已接入账号体系、云保存和云读取入口，完善功能正在开发中！

## 🚀 本地开发

### 环境要求

- `Node.js` `^20.19.0 || >=22.12.0`

### 安装依赖

```bash
npm install
```

### 启动 Web 开发环境

```bash
npm run dev
```

### 构建前端资源

```bash
npm run build
```

### 启动 Electron 桌面端

```bash
npm run app:start
```

### 构建桌面安装包

```bash
npm run app:build
```

当前仓库已配置 Electron 构建目标：
- `macOS`：`dmg`

## 🗂️ 当前主要界面

- `存档选择`：进入、新建、导入导出存档
- `商店`：购买和解锁树种
- `密涅瓦地图`：按主题进入森林巡视
- `森林巡视`：以项目列表浏览某个主题下的项目
- `项目仪表盘`：进行专注、种树和收获
- `巡林官手记`：查看与编辑植树日志、查看系统日志
